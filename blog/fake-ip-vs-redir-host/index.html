一、Redir-Host 模式：传统而稳妥的 DNS 解析

本地客户端必须先完成一次真实的 DNS 域名解析获取目标 IP，再根据 IP 判断是否走代理，由于需要等待 DNS 返回，首屏略有延迟。

二、Fake-IP 模式：秒速返回的虚拟假 IP 革命

无论你请求什么域名，Clash 本地立刻分配一个 198.18.x.x 的虚拟保留地址，彻底省去了本地 DNS 查询耗时，打开海外网页极度丝滑。

三、常见避坑与适用场景

Fake-IP 在绝大多数场景下是首选；但在部分强制校验真实 IP 的旧款外服游戏或特殊内网企业 VPN 下，建议将该域名加入 Fake-IP 过滤名单。
