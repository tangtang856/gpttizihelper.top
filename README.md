## 🚀 架构革新：告别机械重复，重构现代紧凑版面

本次重构彻底解决了旧框架中“首页卡片排完表格排、各个分类内容雷同、整页机械重复堆砌”的痛点：

1. **紧凑型首页科技媒体架构**：
   - **Hero 模块**：醒目的品牌标识与 4 大快捷入口桌面端一行并排，响应式优雅适配。
   - **TOP 4 避坑核心神机**：编辑部基于丢包实测严选代表性首选（性价比王、专线防封王、追剧王、商务办公王），拒绝机械列出全部 14 个卡片。
   - **14 品牌速查对比矩阵**：带分类 Tab（`全部` / `🚀 纯专线` / `💰 白菜平价` / `🤖 原生IP`）的交互式矩阵，兼顾全量数据展示与视觉轻量化。
   - **场景智能导购向导**：按使用场景（ChatGPT/Claude、4K流媒体、外服游戏、备用不限时等）对号入座，一键直达精准方案。
   - **精选指南与技术视野**：只展示 4 篇精选指引，避免百篇长文直接占领首页面板。
2. **场景化落地专题 (`/recommend/[category]`)**：
   - 针对平价白菜、高端IPLC专线、新手入门、稳定防断联、大模型AI、4K追剧六大场景，定制专业选型分析与匹配品牌，彻底去除千篇一律的机械套用。
3. **多维天梯排行榜 (`/ranking/[slug]`)**：
   - 包含综合实力榜、每GB性价比榜、最低门槛平价榜与晚高峰稳定性榜，分别依据不同算法真实排序。
4. **横向在线PK对比系统 (`/compare/`)**：
   - 纯客户端响应式对比工具，支持自由勾选 2~4 家品牌实时同屏比对各项硬核参数。
5. **知识与教程专栏 (`/guides/` & `/blog/`)**：
   - 30 篇全平台客户端使用图文教程 + 100 篇避坑与协议深度剖析文章，全部使用 Tailwind 排版优化。

## 🛠️ 常用开发与构建指令

```bash
# 启动本地开发服务器
npm run dev

# 编译打包全站静态页面 (输出至 dist/)
npm run build

# 本地预览编译后的静态站点
npm run preview

# 执行全站 183 页面 SEO 与完整性质检验收
npm run test

# 向 Bing 搜索引擎 IndexNow 接口批量推送全站 URL
npm run indexnow
```
