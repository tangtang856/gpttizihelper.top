💡 安卓首选客户端

目前安卓平台最稳定强大的客户端为 Clash Meta for Android (CMFA) 与 Sing-box。对 VLESS、Trojan 等新协议支持极佳。

一、安装与权限设置

从官方渠道下载 .apk 文件安装后，初次启动时安卓系统会弹出“创建 VPN 连接请求”提示框，必须点击确定/允许，否则客户端无法接管网络流量。

二、配置订阅链接

  1. 进入机场后台，复制“Clash订阅”链接；
  2. 打开 Clash Meta，点击 配置 (Profiles) → 点击右上角 +号 → 选择 从 URL 导入；
  3. 名称随意填写，在 URL 栏粘贴刚才复制的订阅链接；
  4. 点击右上角保存图标，等待节点列表下载完毕并选中该配置。
