v2rayN 电脑端全协议上手配置教程（VLESS/Trojan/SS订阅）

📅 最新适配版本: 2026年稳定版 ⏱️ 阅读时间: 约 5 分钟 🔰 难度等级: 新手入门级 💻 目标平台: Windows

一、v2rayN 的核心优势

v2rayN 是 Windows 平台上资历最老、兼容性最全的开源代理工具。它不仅原生支持 Xray 核心的全部最新特性（包括 VLESS-XTLS、Reality、Trojan），还能精准控制每个协议的参数，适合喜欢极高可控性的用户。

二、安装与核心组件检查

  1. 下载 v2rayN-with-Core.zip 官方整合包；
  2. 解压至非系统盘（避免 Windows 权限拦截，推荐 D:\Software\v2rayN）；
  3. 运行 v2rayN.exe，如果提示缺少 .NET 运行时，根据弹窗提示前往微软官网下载安装 .NET 6 或 .NET 8 Desktop Runtime。

三、导入机场订阅

  1. 点击顶部菜单栏的 订阅分组 → 订阅分组设置；
  2. 在左下角点击 添加；
  3. 备注输入机场名称（如微风网络），在“可选地址 (url)”栏粘贴从机场复制的 V2Ray/Xray 订阅链接；
  4. 点击确定保存，回到主界面点击 订阅分组 → 通过代理更新订阅（或不通过代理更新）。

四、开启系统代理与分流模式

在窗口底部找到 系统代理 下拉框，选择 自动配置系统代理；右侧 路由 下拉框务必选择 绕过大陆 (Whitelist)。任务栏图标变为红色或蓝色即代表代理已正常生效。
