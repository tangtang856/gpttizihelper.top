Mac 终端 Terminal 与 Git 命令行科学上网极速配置指南

📅 最新适配版本: 2026年稳定版 ⏱️ 阅读时间: 约 5 分钟 🔰 难度等级: 新手入门级 💻 目标平台: macOS

一、为什么开了梯子，终端执行命令依然龟速？

客户端开启的“系统代理”仅对图形界面应用程序（如 Chrome、Safari）生效，而 Mac 系统的 Terminal、iTerm2、Git、Homebrew、Docker 默认完全忽略系统代理，依然直连海外服务器，导致 git clone 频繁断连或速度只有几 KB/s。

二、优雅的一键开关配置方案

打开终端，执行命令编辑 zsh 配置文件：

nano ~/.zshrc

在文件最末尾粘贴以下快捷别名（假设客户端本地混合端口为 7897）：

# 快捷终端代理命令
alias setproxy="export all_proxy=socks5://127.0.0.1:7897; export http_proxy=http://127.0.0.1:7897; export https_proxy=http://127.0.0.1:7897; echo '🚀 终端代理已开启'"
alias unsetproxy="unset all_proxy http_proxy https_proxy; echo '🛑 终端代理已关闭'"
alias checkproxy="curl cip.cc"

保存退出后执行 source ~/.zshrc。以后在任何终端窗口只要输入 setproxy，命令行立刻秒速翻墙；输入 unsetproxy 即可随时复原！
